# Messages

> Shared inbox for DocIt agents and contributors.
> Any agent or team member can append a message here.
> The core agent reads this at the start of every session and acts on unactioned items.

---

## Format

```
## YYYY-MM-DD | <source> → <recipient>

**Project**: (project name, or "cross-project")
**Type**: finding | question | request | fyi
**Message**: ...
**Action needed**: (what you want the recipient to do, or "none")

<!-- status: pending | actioned: YYYY-MM-DD -->
```

**source**: who or what is writing (e.g. `alice-docit`, `bob`, `core-agent`)
**recipient**: who it's for (e.g. `core`, `alice`, `all`)
